## Overview

This repository contains all code, notebooks, outputs, and intermediate datasets for **Sub-Project 2** of the master project *Network Traffic Data Generation for ML-Based Attack Detection in 5G Networks*, conducted at the University of Zurich. Everything in this repository was created exclusively in the scope of this master project.

The pipeline addresses the following research question: can state-of-the-art tabular generative models — specifically **CTAB-GAN (CTGAN)** and **TabDDPM** — augment an existing 5G network intrusion detection dataset to improve the performance of gradient-boosted classifiers on a multi-class attack detection task?

The pipeline operates on two datasets:
- **5G-NIDD** — a publicly available 5G intrusion detection dataset collected from a real 5G testbed ([IEEE DataPort](https://ieee-dataport.org/documents/5g-nidd-comprehensive-network-intrusion-detection-dataset-generated-over-5g-wireless))
- **CEDI-NIDD** — a custom dataset generated by the companion sub-project (Sub-Project 1), produced by the 5G testbed built in that project

## Dataset Variants (5G-NIDD)

The pipeline produces seven distinct training configurations from the 5G-NIDD source dataset, all evaluated against their corresponding held-out test sets. Balanced datasets are always also cleaned datasets.

| Dataset Variant              | Cleaned | Balanced | Augmented | Train Rows | Test Rows  |
|------------------------------|:-------:|:--------:|:---------:|:----------:|:----------:|
| Dirty Raw                    | No      | No       | No        | 160,000    | 243,177    |
| Clean Raw                    | Yes     | No       | No        | 160,000    | 243,177    |
| Balanced Raw                 | Yes     | Yes      | No        | 160,000    | 243,177    |
| CTGAN — Balanced Augmented   | Yes     | Yes      | CTGAN     | 320,000    | 243,177    |
| CTGAN — Per-Class Augmented  | Yes     | Yes      | CTGAN     | 320,000    | merged     |
| tabDDPM — Balanced Augmented | Yes     | Yes      | tabDDPM   | 320,000    | 243,177    |
| tabDDPM — Per-Class Augmented| Yes     | Yes      | tabDDPM   | 320,000    | merged     |

**Attack classes (9 total):** Benign, HTTPFlood, ICMPFlood, SYNFlood, SYNScan, SlowrateDoS, TCPConnectScan, UDPFlood, UDPScan

## Pipeline Execution Order

The notebooks must be executed in the following order for the 5G-NIDD pipeline. The CEDI-NIDD pipeline is independent.

### 5G-NIDD Pipeline

```
Step 1 — Dataset preparation
  └── 5G_NIDD_Dataset_Raw_Production.ipynb          → Dirty Raw + Clean Raw splits
  └── 5G_NIDD_Dataset_Balancing_Splitting.ipynb     → Balanced splits + per-class splits

Step 2 — Augmentation preparation (run for each class + Balanced; both models)
  └── 5G_NIDD_CTGAN_Augmentation_Prep.ipynb         → Prep for CTGAN
  └── 5G_NIDD_tabDDPM_Augmentation_Prep.ipynb       → Prep for tabDDPM

Step 3 — Augmentation training (run for each class + Balanced; both models)
  └── 5G_NIDD_CTGAN_Augmentation_Training.ipynb     → Generate CTGAN synthetic data
  └── 5G_NIDD_tabDDPM_Augmentation_Training.ipynb   → Generate tabDDPM synthetic data

Step 4 — Post-augmentation merge
  └── 5G_NIDD_prep_after_aug_balanced_datasets.ipynb    → Merge for balanced strategy
  └── 5G_NIDD_prep_after_aug_per_class_datasets.ipynb   → Merge for per-class strategy

Step 5 — Classification and evaluation
  └── 5G_NIDD_Classifier_GBDT.ipynb                 → Train all classifiers on all datasets
  └── 5G_NIDD_evaluate_classifier_models_GBDT.ipynb → Evaluate, compare, and plot results
```

### CEDI-NIDD Pipeline

```
Step 1 — Dataset construction
  └── cedi-nidd/pcap_dataset_builder.ipynb          → PCAP → windowed tabular features

Step 2 — Preparation
  └── cedi-nidd/prep_cedi_nidd_gbdt.ipynb           → Label normalisation + cleaning

Step 3 — Classification and evaluation (shared notebooks)
  └── 5G_NIDD_Classifier_GBDT.ipynb                 → Train classifiers on CEDI-NIDD
  └── 5G_NIDD_evaluate_classifier_models_GBDT.ipynb → Evaluate CEDI-NIDD classifiers
```

## Environment Setup

All notebooks were developed and executed on **Ubuntu 24.04 LTS** with **Python 3.12.3** in a Conda environment named `ganenv`. GPU acceleration (CUDA) was used for generative model training and GBDT classifier training.

### Install dependencies

```bash
conda create -n ganenv python=3.12.3
conda activate ganenv

pip install pandas numpy scikit-learn matplotlib tqdm joblib pyarrow
pip install xgboost lightgbm catboost
pip install ctgan
pip install synthcity          # provides the tabDDPM (ddpm) plugin
pip install torch              # GPU build recommended
```

> **Note:** Large files (trained models, synthetic datasets, processed CSVs) are stored via **Git LFS**. Run `git lfs pull` after cloning to download them.

### Running notebooks remotely

For long training jobs on a remote GPU server, see [`README_VM_Jupyter.md`](README_VM_Jupyter.md) for the SSH tunnel and `screen`-based workflow.

## Reproducibility

All experiments use a fixed random seed of **42** throughout the entire pipeline — for dataset splits, generative model training, synthetic sample generation, classifier training, and validation splits. SHA-256 checksums of all preparation outputs are recorded in `prep_preparation_summary.json` files within each augmentation run directory.
